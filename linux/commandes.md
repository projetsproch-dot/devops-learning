# Commandes Linux de base

## Navigation

### `pwd`

Affiche le répertoire courant.

```bash
pwd


ls
Affiche le contenu d’un dossier.
ls
ls -la
cd
Permet de changer de dossier.
cd /tmp
cd ..
cd ~
Fichiers et dossiers
mkdir
Crée un dossier.
mkdir test
touch
Crée un fichier vide.
touch fichier.txt
cp
Copie un fichier ou un dossier.
cp fichier.txt sauvegarde.txt
mv
Déplace ou renomme un fichier.
mv fichier.txt nouveau_nom.txt
rm
Supprime un fichier.
rm fichier.txt
⚠️ Attention : la suppression avec rm est généralement définitive.
Lecture et recherche
cat
Affiche le contenu d’un fichier.
cat fichier.txt
grep
Recherche un mot dans un fichier.
grep "mot" fichier.txt
find
Recherche un fichier ou un dossier.
find . -name "*.txt"
